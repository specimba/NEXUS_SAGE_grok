# Skin V2 — 5 loved references (Scout)

Companion to SKIN-V2-PHOSPHOR.md. Steal craft, not pixels. No Matrix rain wallpaper as chrome (≤8% stage-behind rain only if Reviewer re-gates).

1. katagami Phosphor — https://katagami.ai/language/en-019ef84f-80c1-7b90-b6fb-7ff2c528f454 — Steal: green-monochrome ops console, black-glass panels, amber corner ticks, block cursor, scanline ≤4%, audited not parody. Ban: neon flood, rain wallpaper.

2. Pipboy.Avalonia (green default) — https://github.com/NeverMorewd/Pipboy.Avalonia — demo https://nevermorewd.github.io/Pipboy.Avalonia/ — Steal: sharp corners, phosphor green as primary, amber as accent switch. Ban: amber-as-only-Fallout.

3. HA Pip-Boy green wasteland CRT — https://github.com/iosue-iulianus/homeassistant-pipboy-theme — Steal: phosphor green on near-black, partial borders top+right, scanlines vignette flicker, Share Tech Mono, green=nominal amber=caution. Ban: rounded Apple cards, cyan fills.

4. afterglow-crt crt-green — https://github.com/HauntedCrusader/afterglow-crt — Steal: pure CSS CRT overlay scanlines beam breath warp via CSS vars; crt-green preset. Ban: heavy warp that kills readability; amber preset as primary.

5. Codemotion Pip-Boy 3000 CSS — https://www.codemotion.com/magazine/frontend/creating-a-fallout-style-ui-using-modern-css/ — Steal: CSS CRT band + inset glow + scan without WebGL; prefers-reduced-motion. Ban: 3D prop chrome, gimmick-first UI.

Hierarchy: primary green #33ff66; amber scarce accent; cyan/magenta 1px sparks only; rain optional ≤8% behind stage; free providers only (no paid X).
