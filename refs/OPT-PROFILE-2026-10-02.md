# Optimization profile — 2026-10-02 07:50–07:55 UTC+3 (Architect)

Measured on a copy (`/tmp/prof/desk`) of main at `72f865f`. The shared computer's load average was 8–45 during the run, so treat the absolute times as noisy.

## Baseline
- **Build:** `bun run build` takes ≈ 20 s (compile 6.6 s, tsc 4.7 s, eslint 5.4 s). Not worth optimizing.
- **Page weight:** `out/` is 1.31 MB raw, 376 KB gzipped. First Load JS for `/` is 214 kB. The page chunk is 370 KB raw / 103 KB gz, and about **86 KB gz of it is `src/data/*.ts`**, bundled into the client because `desk.tsx` is `"use client"` and imports the data directly.
- **Crawl:** sources run **one after another** (`sources_ms` 42 663 vs `wall_ms` 42 990 at 03:14Z). Over the last 15 crawls, wall time was 12–203 s. Lab RSS takes 16–18 s whenever its cache refreshes. **arXiv took 102–164 s for 4–12 rows in 3 of 15 crawls**, because `getAtom` in `src/lib/arxiv-enrich.ts` calls `fetch` with no timeout.
- **Tests:** 510/510 in 74 s while the load average was 45. The per-file sum on a quieter box is 19.9 s, of which **≈ 18 s is real throttle sleep**: `hn-pulse` 10 s, `gnews-rss` 6 s, `rss-labs` 2 s (`*_MIN_INTERVAL_MS = 2000`, and the tests use the real `setTimeout`). Tests also leave cache dirs inside the real `artifacts/sage/` (`hn-cache-test-5xx`, `hn-cache-test-rotate`, `gnews-cache-test-lab-<ts>`, `openalex-cache-test-*`, `crossref-cache-test-budget`).

## Top 3 wins (ranked)
1. **Crawl: run the sources concurrently and put a time budget on arXiv.** Run the 10 sources in parallel with `Promise.allSettled`, keeping each source's own throttle. Give every source fetch an `AbortSignal.timeout` (arXiv budget 20 s, then fall back to cache or soft-fail). Expected: a typical crawl drops from 43 s to ≈ 18 s (bounded by lab RSS), and the worst case from 203 s to ≈ 25 s. Pass mark: `wall_ms` < 1.2 × the slowest source in `ingest-last.json`, plus a test where a hung arXiv mock soft-fails in ≤ 20 s.
2. **Tests: inject the sleep and clock, and use temp dirs.** Pass `sleep`/`minIntervalMs` through the existing `fetchImpl`-style options so tests run with 0 ms. Move every test cache to `mkdtemp`. Expected: suite ≈ 20 s → ≈ 3 s when isolated, a much smaller timeout risk under load, and no test writes into the real data folder while the crawl runs. Pass mark: `bun test` < 5 s on a quiet box, and `git status`/`ls artifacts/sage` unchanged after a run.
3. **Page: ship one slim view of the data instead of all the raw source files.** `pulse-clusters.ts` repeats 340 of its 368 URLs, which are also in `hn-pulse`/`rss-labs`/`gnews-rss`/`rss-security`, and all five files ship to the browser. Generate one `desk-view.ts` at ingest time with only the fields the desk renders, keyed by id. Expected: roughly a 25–40 KB gz cut from the 214 kB first load, plus less JS to parse on a phone (helps Beat 12). Pass mark: First Load JS for `/` ≤ 185 kB, `visual:check` OK, and a byte-identical `index.html` text render.
